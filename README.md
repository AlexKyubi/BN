# 🏷️ Bonus Navigator

Приложение каталога товаров с QR-сканером и PWA поддержкой.

## 📱 Функции

- **CSV каталог** — загрузка товаров из Google Sheets
- **⭐ Фильтр по рейтингу** — 0-5 звёзд (0-100%)
- **🏷️ Категории** — боковая панель с фильтрацией
- **🔍 Поиск** — быстрый поиск по названию и артикулу
- **📸 QR сканер** — распознавание кодов товаров
- **📱 Отзывчивый дизайн** — мобильная оптимизация
- **🔌 Офлайн режим** — Service Worker кэширование
- **📲 PWA** — установка как приложение на смартфон
- **🔐 Авторизация** — вход один раз с сохранением на устройстве

## 🔐 Авторизация

- При первом запуске нужно ввести логин и пароль
- Логин вводится в формате: **Фамилия Имя**
- При входе указывается **CSV-ссылка Google Sheets**
- После успешного входа статус сохраняется в браузере (`localStorage`), повторный вход на этом устройстве не требуется
- Логин/пароль по умолчанию:
   - Логин: любое корректное Фамилия Имя
   - Пароль: `HaierGroup`

## ⚙️ Runtime-конфиг (без хранения в git)

- `public/runtime-config.js` можно использовать для локального переопределения настроек, но для работы сайта на GitHub Pages он не обязателен
- В репозитории хранится только шаблон `public/runtime-config.example.js`
- Ссылку Google Sheets можно не хранить в runtime-конфиге: пользователь вводит её при авторизации, и она сохраняется локально на устройстве

Перед запуском/деплоем:
1. Скопируйте `public/runtime-config.example.js` в `public/runtime-config.js`
2. Укажите реальные значения, если хотите переопределить стандартные:
   - `googleSheetUrl`
   - `defaultPassword`

## 🚀 Быстрый старт

### Локальное развёртывание

1. **Live Server** (VS Code)
   ```
   Правой клик на index.html → "Open with Live Server"
   ```
   Откроется на `http://localhost:5500`

2. **Python**
   ```bash
   python -m http.server 5500
   ```

3. **Node.js / http-server**
   ```bash
   npx http-server -p 5500
   ```

### PWA установка

- **Chrome/Edge**: Нажми кнопку 📥 в header
- **Safari (iOS)**: Поделись → "На экран Домой"
- **Firefox**: Нажми кнопку 📌 адреса

## 📊 Данные товаров

Приложение загружает товары из:
1. **Google Sheets** (основной источник) — обновляется в реальном времени
2. **Кэш браузера** — хранится 6 часов
3. **Локальный файл** — `public/products.csv` (опциональный fallback)

## 🎨 Структура данных CSV

```
Бренд,Категория,Тип,Модель,Процент,Изображение
Samsung,Телефоны,Смартфон,Galaxy A12,45,460033.webp
```

Колонки (обязательные):
- **Бренд** — производитель
- **Категория** — фильтр боковой панели
- **Тип** — подкатегория
- **Модель** — название товара
- **Процент** — рейтинг 0-100%
- **Изображение** — имя файла в папке `images/`

## 🔧 Разработка

### Служебные скрипты

Если нужны локальные утилиты, храните их в отдельной папке `tools/` (по желанию). В текущей структуре служебные каталоги удалены.

### Обновление Service Worker

При изменении версии приложения обновите `CACHE_NAME` в `sw.js`:
```javascript
const CACHE_NAME = 'bonus-navigator-v2'; // v1 → v2
```
