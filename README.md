# Bonus Navigator

Bonus Navigator — веб-приложение для просмотра каталога товаров, региональных цен и остатков, а также локального учёта личных продаж и комиссий.

## Назначение

Система обеспечивает удобный доступ к товарному каталогу, поиск по атрибутам, просмотр карточек товаров и работу с региональными данными. Основная задача проекта — дать пользователю понятный интерфейс для взаимодействия с каталогом и данными о наличии товаров.

## Архитектура

Проект состоит из двух основных частей:

- Frontend — клиентская часть на HTML, CSS и JavaScript, реализующая интерфейс, фильтрацию и навигацию.
- Backend proxy — серверный модуль на Python, который получает данные из внешних источников и передаёт их клиенту в удобном формате.

## Основные возможности

- просмотр каталога товаров;
- поиск по артикулу или модели и фильтрация по категориям, комиссии и наличию;
- карточки товаров с основной информацией;
- работа с региональными и складскими данными;
- личный кабинет с аналитикой, редактированием продаж и месячными отчётами XLSX;
- экспорт и объединяющий импорт локальной истории между устройствами;
- поддержка Progressive Web App для работы в браузере и на мобильных устройствах.

История продаж хранится только в хранилище браузера пользователя и не отправляется на backend. Чтобы не потерять её при удалении браузера или очистке данных сайта, необходимо периодически делать экспорт.

## Требования

- современный браузер с поддержкой JavaScript;
- Python 3 для запуска серверной части;
- доступ к конфигурационным файлам и внешним данным, используемым приложением.

## Локальный просмотр frontend

Статические файлы необходимо открывать через локальный HTTP-сервер, а не через `file://`. Для полноценной работы требуется совместимый backend и разрешённый Origin.

## Конфигурация

Публичный репозиторий содержит только frontend. Backend, рабочая конфигурация, каталог, база, логи, резервные копии и внутренняя карта проекта исключены из Git. Секреты должны храниться только в защищённой конфигурации VM или переменных окружения.
